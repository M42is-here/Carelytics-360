# 🏥 Carelytics-360
### Healthcare Data Analysis & Insights Using Microsoft Excel

**Turning Healthcare Data into Meaningful Insights.**

Carelytics-360 is a healthcare data analytics project focused on exploring patient health profiles, medical histories, and healthcare costs using Microsoft Excel.

This project combines data cleaning, transformation, data exploration, analytical techniques, and visualization to uncover meaningful patterns and relationships within healthcare data.

---

## 🎯 Project Objectives

- Clean and prepare raw healthcare datasets.
- Transform patient information into meaningful analytical categories.
- Combine multiple datasets using Customer ID.
- Analyze relationships between health conditions and healthcare expenses.
- Build visualizations to communicate key findings.
- Present analytical insights through a consolidated dashboard.

## 📂 Dataset Overview

The project uses three datasets:

| Dataset | Description |
|---|---|
| Customer Names | Customer identification and name details |
| Medical Examinations | BMI, HbA1C, heart issues, transplants, cancer history, surgeries and smoking status |
| Hospitalisation Details | Date of birth, charges, hospital tier, city tier and state information |

## 🔍 Project Workflow

### 1. Data Cleaning
- Identified and counted missing values.
- Handled missing month and year values.
- Replaced missing categorical values using mode.
- Handled missing State ID values.

### 2. Data Transformation
- Split customer names into Title, First Name and Last Name.
- Converted major surgeries into numerical values.
- Reviewed inconsistencies in Heart Issues and Smoker columns.
- Categorized BMI into Weight Status.
- Categorized HbA1C into Diabetes Status.
- Created Date of Birth from year, month and date.
- Calculated customer age based on 8 June 2023.
- Formatted healthcare charges as currency ($).

### 3. Data Integration
Combined all three datasets into a single **Healthcare** worksheet using Customer ID as the common key and VLOOKUP.

The consolidated dataset contains 17 analytical columns.

### 4. Data Analysis & Visualization

The project explores six key analytical questions through eight visualizations.

| Analysis | Visualization |
|---|---|
| Cancer history among smokers and non-smokers | Doughnut Chart |
| Major surgeries by transplant history | Column Chart |
| Average HbA1C by transplant history | Chart |
| Healthcare charges by weight and diabetes status | Column Chart |
| Average charges by hospital tier across states | Column Chart |
| Age vs BMI | Scatter Plot |
| Age vs HbA1C | Scatter Plot |
| Age vs Healthcare Charges | Scatter Plot |

### 5. Dashboard

Created a consolidated Healthcare Dashboard containing all eight visualizations to present the key analytical insights in one place.
